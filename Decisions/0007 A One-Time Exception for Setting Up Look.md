# 7. A One-Time Exception for Setting Up Look

Decided by the owner on 26 November 2026.

**Context.** Look is the set of parts every app is built from, and the owner wants it whole before the
apps lean on it. How a thing moves is a handful of exact numbers, a spring's response and damping or a
duration, which filming another app does not recover. Search's were tuned frame by frame on a real Mac,
and Search is MIT licensed.

**Decision.** Once, while Look is set up, two principles are set aside for Look alone. Its parts are
built whole, ahead of need, as `spec/look.md` lists them. Its motion is taken from Search word for word,
with Search's copyright line and permission notice kept beside it and in each app's About window. The
parts themselves are still measured and written fresh.

**Consequences.** The exception ends when the owner approves Look's first set of parts, and the pull
request that finishes that set deletes the lines in `SPEC.md` and `CLAUDE.md` that point here. From
then on, a new part is written when an app needs it, and nothing is pasted. The motion already taken
stays, with its notice. Later changes in Search are not taken.
