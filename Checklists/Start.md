# Before Starting

Read every line, every session. If a line is false, stop and say so: never tidy away work
that may be another session's.

- [ ] `git status` is clean, and nothing is stashed.
- [ ] I am on `main`, and `git pull` says it is up to date.
- [ ] No branch exists but `main`, here or on GitHub, unless it has an open pull request.
- [ ] `NOW` names the app in work. I will touch no other.
- [ ] No release of that app is waiting on the owner.
- [ ] I know the one issue I am taking, or have made it from the owner's words. No branch on GitHub
      starts with its number: pushing mine claims it.
- [ ] `Scripts/check` is green before I change anything.
