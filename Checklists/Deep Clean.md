# A Deep Clean

Before each new app, and whenever the owner asks. It changes the shape of things and never what an app does.
Read every line.

- [ ] Measure first: files and lines by folder, in this repository and in the private notes. Keep the numbers.
- [ ] Read every file. Note what is dead, written twice, said in two places, stale, misnamed or misplaced.
      "Dead" is proved by searching the whole repository for the name, never guessed.
- [ ] Nothing that works, and nothing a spec asks for, is removed to make the number bigger. Say the honest number.
- [ ] Each change is one issue and one pull request, like any other. The same tests pass before and after, and
      no picture changes.
- [ ] A file is named for what it holds, and a test for the file it tests.
- [ ] A fact has one home. Every other page points at it and does not repeat it.
- [ ] What `.github/CODEOWNERS` gives the owner comes to him as one pull request for each subject.
- [ ] In the private notes: finished work moves to `History`, and the notes keep only what is written nowhere else.
- [ ] Each line budget in `CONSTRAINTS.md` is set to what its module now needs.
- [ ] The owner is shown one page: each repository before and after, the map, what was removed, what waits for him.
